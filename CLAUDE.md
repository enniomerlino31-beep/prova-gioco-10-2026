REGOLA FONDAMENTALE: il README.md deve essere sempre aggiornato. Ogni volta che modifichi il progetto (nuove funzioni, controlli, file, comandi, correzioni importanti), prima di fare commit aggiorna anche il README: le sezioni Stato attuale, Comandi, Struttura dei file se cambiano, e aggiungi una riga al Registro modifiche. Non fare mai commit di modifiche al gioco senza aver aggiornato il README nello stesso commit.

All'inizio di ogni nuova sessione leggi README.md e PIANO-GRUPPI.md (e PIANO-ESPANSIONI.md se serve).

Rispondi sempre in italiano, con spiegazioni semplici adatte a un principiante.
